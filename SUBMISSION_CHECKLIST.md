# Coursera submission checklist

## Project title

Little Lemon Food Ordering App - React Native Capstone

## Before submitting

- Run `npm install`.
- Run `npx expo start`.
- Test the full rubric once.
- Confirm `design/wireframe.jpg` is present.
- Commit every project file and the wireframe to your GitHub repository.

## Git commands

```bash
git init
git add .
git commit -m "Complete Little Lemon React Native capstone"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

Create an empty GitHub repository first, then replace `YOUR_GITHUB_REPOSITORY_URL` with its HTTPS URL.

## Rubric self-check

Expected results:

- Onboarding appears on first launch: Yes
- First name + email required: Yes
- Next enabled only after valid details: Yes
- Relaunch after onboarding opens Home: Yes
- Home contains header, hero, menu breakdown, food menu list: Yes
- Profile is pre-populated: Yes
- Saved Profile changes survive restart: Yes
- Logout clears Profile/onboarding data: Yes
- Back button returns to Home: Yes
- Hero has restaurant description + search: Yes
- Menu categories are selectable: Yes
- Menu list shows name, description, price, and image: Yes
- Search for `salad` filters by dish name: Yes
- Mains + Desserts shows Grilled Fish, Pasta, Lemon Dessert: Yes
- Design follows the wireframe and Little Lemon branding: Yes

## Suggested peer-review feedback text

The application is easy to navigate and the main flow works consistently from onboarding to the menu and profile screens. User details are stored correctly, and both search and category filters make the menu practical to browse. The visual hierarchy also follows the wireframe and Little Lemon brand style. A useful future improvement would be to add a small loading or success indicator when profile data is saved or menu data is refreshed.
